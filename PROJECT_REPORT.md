# Mini Project Report
## Job Portal with AI-Based Resume Screening

### Problem Statement
Job seekers spend considerable time searching across multiple platforms, while recruiters face a large number of resumes. The system automatically extracts skills from resumes and compares them with job requirements.

### Objectives
1. Build a web-based job portal for applicants and recruiters.
2. Provide secure authentication and role-based access.
3. Extract skills from resumes using NLP.
4. Generate a candidate-job match score.
5. Provide applicant and recruiter dashboards.

### Technology Stack
Frontend: React
Backend: Node.js + Express.js
Database: MongoDB
AI/NLP: Python
Version Control: Git/GitHub
IDE: Visual Studio Code

### Modules
Applicant module, Recruiter module, Job module, Application module, Resume Screening module, Matching module.

### Future Scope
Advanced machine-learning ranking, better PDF/DOCX parsing, email notifications, recommendations, and deployment to cloud platforms.
